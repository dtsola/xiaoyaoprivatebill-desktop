### 6.2 新增技术债

| 项 | 说明 | 偿还触发条件 |

## 7. 风险与决策

### 7.1 Top 5 风险

| # | 风险 | 影响 | 应对 |
|---|---|---|---|
| 1 | pandas 语义复刻偏差 | 数字与 Web 版不一致 | golden 对账 + 18 项 pycompat 单测 |
| 2 | 27 接口响应形状不统一 | 前端解析失败 | 逐个复刻，表驱动契约测试 |
| 3 | macOS 无本机构建、未签名 | 无法交付 dmg / 安装摩擦 | GitHub Actions + 文档说明 |
| 4 | MCP 本地端口被滥用 | 账单泄露/被删 | 默认关闭、Token、回环、审计、软删除 |
| 5 | Rust 重写经验不足 | 工期延长 | 先打通最小闭环，长尾后置 |

### 7.2 决策日志

| 日期 | 决策 | 原因 |
|---|---|---|
| 2026-11-11 | 采用 Tauri v2 + Rust 全量重写 | 体积、隐私叙事、前端复用率 |
| 2026-11-11 | 前端只允许改 8 个文件 | 控制联调返工，保证视觉一致 |
| 2026-11-11 | 27 接口全量移植 | Rust 后端可完全替代 Web 后端 |
| 2026-11-11 | MCP 默认关闭 | 隐私承诺与误操作风险 |
| 2026-11-11 | 保留 D1–D7 | 统计口径一致；修复需独立版本 |
| 2026-11-11 | 不做自动更新/遥测 | 完全离线的隐私承诺 |

### 7.3 与 Web 版进度切割

- 本文件不记录 Web 版「前后端重构已全部完成」的历史；那是另一个产品线。
- Web 版的状态只作为 `web-baseline` 的技术输入，不代表桌面版进度。
- 桌面版从 0 开始，按 M1–M6 推进。
