```rust
pub struct Transaction {
    pub time: NaiveDateTime,
    pub category: String,        // 交易分类
    pub counterparty: String,    // 交易对方
    pub description: String,     // 商品说明
    pub direction: String,       // 收/支：收入 / 支出 / "/"
    pub amount: f64,             // 支出为负，收入为正；退款逻辑按 Python
    pub payment_method: String,  // 收/付款方式
    pub status: String,          // 交易状态
    pub source: String,          // 支付宝 / 微信
    pub month: String,           // YYYY-MM
    pub date: String,            // YYYY-MM-DD
    pub is_refund: bool,
}
```

## 十二、风险、回滚与版本门槛

### 12.1 进度风险与应对

| 风险 | 触发信号 | 应对 |
|---|---|---|
| pandas 对账耗时超预期 | P2 第 3 天仍有 >5 个接口不绿 | 先冻结 18 个在用接口，9 个兼容接口延后到 0.2.0 |
| rmcp API 不稳定 | P4 编译 spike 失败 | 锁定更早的 3.x 版本；仍失败则手写 JSON-RPC 最小实现（仅 `tools/list` + `tools/call`） |
| macOS CI 不可用 | runner 拉取失败/构建超时 | 本机 Windows 先发布；macOS 顺延，文档标注「构建中」 |
| Tauri 插件权限问题 | dialog/opener 调用被拒 | 查 capabilities；外链降级为前端 `<a>` + 系统默认浏览器 |
| 性能不达标 | 1 万条 `/analysis` > 200ms | 按 `(generation, params)` 缓存分析结果；预计算年度聚合 |

### 12.2 回滚策略

- **发布回滚**：保留上一版安装包；数据目录带 `schema_version`，新版本只做向前兼容迁移。
- **对账失败**：不发布；保留 `0.1.0` 开发版。
- **数据损坏**：启动 reconcile + 回收站/快照恢复；每次破坏性操作前有快照/托管。
- **MCP 故障**：「AI Agent 接入」页可关闭；关闭后不影响 GUI 全部功能。

### 12.3 版本门槛

| 版本 | 条件 |
|---|---|
| `0.1.0` | M1–M3 完成（可运行、可导入、18 个接口 + 9 页面） |
| `0.2.0` | M4（27 接口对账） |
| `0.3.0` | M5（MCP 14 工具） |
